# THE OASIS

A cinematic luxury cafe inspired by the world's most beautiful deserts. Architecture, sand, light, and water merge into a calm digital oasis.

## Brand Identity

- **Concept:** Desert Luxury, Minimal Architecture, Cinematic Storytelling
- **Colors:** Sand #E7D8BE, Dune #C8A97E, Terracotta #B56A44, Stone #F5F1EA, Oasis Green #4B7F67, Charcoal #1A1A1A
- **Typography:** Display=Canela (fallback: Editorial New), Body=Inter (fallback: Suisse Intl)

## Tech Stack

- Vite + React + TypeScript
- SCSS for styling
- GSAP for animations
- Lenis for smooth scrolling
- SplitType for text animations

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Sections

1. **Loader** - Wind particles, sand floating, heat distortion, logo reveal
2. **Hero** - Full-screen oasis, animated dunes, palm reflections, water ripple, parallax mountains
3. **Story** - Ancient caravan routes, animated map, editorial layout
4. **Signature Drinks** - Large image cards, hover reveals, sand particles follow cursor
5. **Oasis Garden** - Interactive palms, moving sunlight, water reflections
6. **Architecture** - Travertine textures, concrete geometry, cinematic photography
7. **Coffee Journey** - Seed → Farm → Roast → Brew → Cup animated timeline
8. **Gallery** - 15 editorial images, fullscreen expansion
9. **Reservation** - Luxury booking with animated oasis reflections
10. **Footer** - LOOKBOOK Studio Experience
